A personalised 12-week Push / Pull / Legs training plan built for an intermediate natural athlete. Hypertrophy-first, strength-second.

## Programme overview

- **Split:** Push / Pull / Legs, 4 days/week, A/B rotation
- **Periodisation:** Block periodisation across 3 phases
- **Phase 1 (Weeks 1–3):** Volume base, 8–12 rep ranges
- **Phase 2 (Weeks 5–7):** Intensification, 6–10 rep ranges
- **Phase 3 (Weeks 9–11):** Strength expression, 4–6 rep ranges
- **Deloads:** Weeks 4, 8, and 12
- **Cardio:** 20 min post-lift incline treadmill walk every training day
